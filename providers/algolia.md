# Algolia Provider

Use this path when your existing app already speaks an Algolia-style search API and you want a clear starter example for SuggestAPI.

Examples:

- [cURL example](../examples/algolia/curl/search.sh)
- [JavaScript example](../examples/algolia/javascript/search.mjs)
- [InstantSearch adapter example](../examples/algolia/instantsearch-adapter/README.md)

Typical use cases:

- keep an Algolia-like client integration
- move search traffic behind a single SuggestAPI endpoint
- prepare for provider migration with less application churn
